# Каталог товаров

Простое консольное приложение для учета товаров в магазине.

## Что умеет программа:

- Добавлять новые товары
- Искать товары по разным параметрам
- Показывать все товары
- Сохранять данные между запусками
- Кэшировать поиск для скорости

## Как запустить:

1. Открыть проект в IntelliJ IDEA
2. Запустить файл Main.java
3. Использовать логины:
    - admin / 123
    - user / 456
    - или войти как гость
